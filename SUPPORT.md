# Support

Vector does not yet have a supported production release.

- Ask usage and architecture questions in [GitHub Discussions](https://github.com/iteathen/UCI-Arena-Vector/discussions).
- Report reproducible repository, documentation, or contract defects with a [GitHub issue](https://github.com/iteathen/UCI-Arena-Vector/issues/new/choose).
- Propose ownership or connector changes with the architecture issue form.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

Please include the exact revision, operating system, Node.js version, relevant GPU/driver/toolkit identity when applicable, minimal reproduction, expected result, and actual result. Public support does not cover private forks, unpublished dependency revisions, or unredacted credentials.
